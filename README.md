# OMOnewtab（Edge 插件）

> **🤖 AI 开发声明**：本项目**完全由 AI 开发**——全部代码、样式、图标与文档均由 AI 助手（WorkBuddy + DeepSeek）生成，人类仅提出需求与体验反馈，未手写任何一行代码。

一个直接管理**浏览器原生收藏夹**的新标签页插件：紧凑列表展示收藏，支持新建/编辑/删除/文件夹，带搜索栏与时钟。收藏数据存在浏览器里，随你的微软账号自动同步到所有电脑。

## 功能
- **双页布局**：上下翻页切换——「工作页」与「私人页」，底部两个小圆点指示当前页
- **工作页**：大时钟 + 日期 + **天气**（免费接口，城市在 `newtab.js` 顶部 `WEATHER_CITY` 修改）+ 搜索栏（回车直达网址或搜索）+ 工作工具快捷入口（默认内置邮箱/日历/会议/文档/企业微信/翻译，可在 `newtab.js` 顶部 `WORK_TOOLS` 数组中自由增删改）
- **私人页**：收藏夹紧凑列表（图标 + 标题 + 域名，点击打开，Ctrl/中键点击在新标签页打开）
- 增删改：行内编辑、删除（含文件夹递归删除）、新建收藏/文件夹
- 右键菜单：收藏上右键＝打开/编辑/删除；空白处右键＝新建
- 实时刷新：在浏览器里改动收藏，页面自动更新

## 在 Edge 中安装（每台电脑只需做一次）
1. 打开 Edge，地址栏输入 `edge://extensions` 回车
2. 打开左上角「**开发人员模式**」开关
3. 点「**加载解压的扩展**」，选择 `my-newtab` 文件夹
4. 在扩展卡片点「**详细信息**」，打开「**设为新标签页替代**」开关
5. 新建一个标签页即可看到效果

> 注意：如果装了其它新标签页插件，多个覆盖类扩展互斥，最后开启「设为新标签页替代」的那个生效。

## 修改代码后如何生效
1. 在 VS Code 中改完代码保存
2. 回到 `edge://extensions`，点该插件卡片上的「**刷新**」按钮
3. 重新打开一个新标签页

## 多台电脑同步（云盘方案）
1. 把 `my-newtab` 文件夹放进云盘同步目录（如 OneDrive 文档目录）
2. 每台电脑按上面的「在 Edge 中安装」步骤，选择**同一个云盘目录下的** `my-newtab` 文件夹加载一次
3. 之后在任意电脑改代码 → 云盘自动同步 → 其他电脑点「刷新」即可
4. 注意：文件夹要一直待在云盘目录里，不要挪走；每台电脑的云盘路径建议保持一致

## 常见问题
- **图标不显示**：favicon 会依次尝试「浏览器缓存 → 国内 CDN → 首字母占位」，占位一定显示，不影响使用
- **修改收藏夹不刷新**：正常会自动刷新；若没反应，点扩展卡片的「刷新」再重开标签页
- **搜索栏回车没反应**：可能是中文输入法选词状态，输入完先按 Esc 或点击页面其他地方再回车
