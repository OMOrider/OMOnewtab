# OMOnewtab（Edge 插件）

> **🤖 AI 开发声明**：本项目**完全由 AI 开发**——全部代码、样式、图标与文档均由 AI 助手（WorkBuddy + DeepSeek）生成，人类仅提出需求与体验反馈，未手写任何一行代码。

一个**三页新标签页**插件：第一页「工作页」集中工作相关功能（时钟/搜索/工作工具），第二页「表盘页」放置信息面板（天气卡片 + API 余额监测卡片，可扩展日历/待办等 widget），第三页「私人页」管理浏览器**原生收藏夹**（含「工具B」快捷侧边栏）。收藏数据存在浏览器里，随你的微软账号自动同步到所有电脑。

## 功能

**三页布局（纯翻页模式）**
- 滚轮在页边界处**整页翻转**（永不停留在页与页之间），左侧竖排三个小圆点指示当前页
- 翻页顺序：工作页 ⇄ 表盘页 ⇄ 私人页（相邻页间上下翻动）
- 收藏列表、工具B侧边栏内部可独立滚动，不会误触翻页

**工作页（第一页）**
- **大时钟**（内嵌普惠体，随插件自带）+ 日期
- **搜索栏**：回车直达网址或搜索（**新标签页打开**）、✕ 一键清空、翻页时**飞行动画**跟随到当前页
- **工作工具**：自动同步收藏夹里名为「工具A」的文件夹（favicon 列表），找不到时回退内置工具

**表盘页（第二页）——信息面板集合**
- **天气卡片**：中国天气网数据（itboy 接口，国内权威），当前天气行（德清）+ **始终显示的 7 天预报**（天气文字、彩色图标、高低温）
- **电脑状态卡片**：电池（电量/充电状态/剩余时间，变化时自动更新）、内存占用率（进度条，≥85% 变红）、磁盘占用率（进度条，≥90% 变红）、CPU 型号；内存/磁盘每 5 秒自动刷新
- **API 余额监测卡片**：显示余额（默认打码，点击显示）、状态；「设置 Key」配置后每天自动查询一次 + 手动刷新；「📊 每日消费」在卡片下方展开近 7 天消费柱状图（余额差值法统计）
- 该页为信息面板容器，后续可继续添加日历、待办等小卡片

**私人页（第三页）**
- **左侧「工具B」侧边栏**：自动同步收藏夹里名为「工具B」的文件夹，独立滚动 + 边缘渐隐 + 固定标题
- **中间收藏夹管理**：紧凑列表（图标 + 标题 + 域名），分组/文件夹可折叠；悬停出现编辑/删除按钮；右键菜单（打开/编辑/删除/新建）；实时刷新（浏览器里改收藏，页面自动更新）
- 顶部同款搜索栏

**其他**
- 所有链接点击均在新标签页打开（收藏、工具、搜索）
- 正文使用 Maple Mono NF CN 等宽字体（未安装的电脑自动回退）
- 隐藏页面滚动条，界面干净

## 配置（打开 `newtab.js` 顶部修改）

| 常量 | 作用 | 默认值 |
|---|---|---|
| `WEATHER_CITY` | 天气显示的城市名 | 德清 |
| `WEATHER_CITY_ID` | 城市代码（weather.com.cn URL 里的数字） | 101210203 |
| `WORK_FOLDER` | 工作页工具文件夹名 | 工具A |
| `PRIVATE_FOLDER` | 私人页侧边栏文件夹名 | 工具B |
| `WORK_TOOLS` | 回退内置工具列表（找不到「工具A」时用） | 邮箱/日历/会议… |

- **DeepSeek Key**：在工作页左侧卡片点「设置 Key」填写（只存在本机浏览器扩展存储，不上传、不进代码；每台电脑各填一次）

## 在 Edge 中安装（每台电脑只需做一次）
1. 打开 Edge，地址栏输入 `edge://extensions` 回车
2. 打开左上角「**开发人员模式**」开关
3. 点「**加载解压的扩展**」，选择 `my-newtab` 文件夹
4. 在扩展卡片点「**详细信息**」，打开「**设为新标签页替代**」开关（若没有其他新标签页插件冲突，此开关可能不显示，直接生效）
5. 新建一个标签页即可看到效果

> 注意：如果装了其它新标签页插件，多个覆盖类扩展互斥，最后开启「设为新标签页替代」的那个生效。

## 修改代码后如何生效
- **只改了代码**（JS/CSS/HTML）：新开一个标签页（或 Ctrl+R 刷新）即可
- **改了 manifest.json**（权限/配置变更）：必须到 `edge://extensions` 点扩展卡片上的「重新加载」（需先打开开发人员模式），再新开标签页

## 多台电脑同步（云盘 / NAS 方案）
1. 把 `my-newtab` 文件夹放进云盘同步目录（OneDrive / 坚果云 / NAS 的 Syncthing 等），**不要同步 `.git` 目录**（.stignore 已自动排除）
2. 每台电脑按「在 Edge 中安装」步骤，选择**同一个云盘目录下**的 `my-newtab` 文件夹加载一次
3. 之后在任意电脑改代码 → 自动同步 → 其他电脑新开标签页即生效
4. 注意：文件夹要一直待在云盘目录里，不要挪走；建议每台电脑同步到相同路径

## 常见问题
- **天气不显示**：确认网络能访问 `t.weather.itboy.net`；itboy 失效时会自动回退 Open-Meteo，再失败则整块隐藏不影响页面
- **图标不显示**：favicon 依次尝试「浏览器缓存 → 国内 CDN → 首字母占位」，占位一定显示
- **余额显示「未配置 Key」**：点卡片「设置 Key」粘贴 DeepSeek API Key（sk- 开头）
- **修改收藏夹不刷新**：正常会自动刷新；若没反应，点扩展卡片的「重新加载」再重开标签页
